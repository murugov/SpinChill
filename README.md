# Автоматизированная установка циклического охлаждения (Spin Chilling)

Проект компактного мобильного экспресс-охладителя баночной тары на базе микроконтроллера ESP32, использующий контролируемое вращение емкости в эндотермической среде для разрушения теплового пограничного слоя.

## 🚀 О проекте

В бытовых условиях и сфере HoReCa часто возникает задача экстренного снижения температуры напитков. Традиционные методы (морозильные камеры) неэффективны из-за высокого термического сопротивления пограничного слоя жидкости у стенок тары. 

Данная установка реализует метод **Spin Chilling** — контролируемое вращение баночной тары объемом до 0.5 л по продольной оси в ледосолевом растворе (с температурой до –5°C). Создаваемая вынужденная конвекция и турбулентный режим внутри емкости позволяют сократить время охлаждения с 60 минут до экспресс-режима в несколько минут.

## 🛠 Аппаратная архитектура прототипа

Текущая конфигурация тестового стенда собрана на специализированной плате расширения и питается от сети 12V:

| Компонент | Модель / Описание | Назначение |
| :--- | :--- | :--- |
| **Микроконтроллер** | ESP32 DevKitC (32-bit, Wi-Fi/BLE) | Центральное управляющее устройство |
| **Драйвер мотора** | TB6612FNG (H-Мост) | Управление направлением и скоростью (ШИМ) |
| **Электродвигатель** | JGA25-370 DC 12V (150 RPM) | Силовой привод вращения тары |
| **Стабилизатор питания** | Mini560 Step-Down (5V фиксированный) | Безопасное питание логики ESP32 от 12V |
| **Термодатчик** | DS18B20 (Влагозащищенная капсула) | Контроль температуры охлаждающей среды |
| **Управление** | Физическая тактовая кнопка | Запуск цикла охлаждения по таймеру |
| **Питание системы** | Сетевой блок питания 12V (1.5–2A) | Источник питания силового привода и логики |

## 💻 Стек разработки и программное обеспечение

*   **Среда разработки:** [Zed Editor](https://zed.dev) — легковесный и быстрый кодовый редактор.
*   **Система сборки:** [PlatformIO Core (CLI)](https://platformio.org) — профессиональный C++ тулчейн для эмбеддед-разработки.
*   **Фреймворк:** Arduino Core для ESP32.
*   **Используемые библиотеки:** `OneWire`, `DallasTemperature`.

### Настройка окружения для автодополнения (LSP) в Zed:
Для того чтобы сервер `clangd` в Zed корректно подхватывал все внутренние зависимости ESP32, после инициализации проекта необходимо сгенерировать базу данных компиляции:
```bash
pio run -t compiledb
```

## 🔌 Схема подключения (Hardware Mapping)

| Периферия | Вывод компонента | Вывод ESP32 DevKitC | Примечание |
| :--- | :--- | :--- | :--- |
| **TB6612FNG** | AIN1 | GPIO 12 | Направление вращения 1 |
| **TB6612FNG** | AIN2 | GPIO 14 | Направление вращения 2 |
| **TB6612FNG** | PWMA | GPIO 13 | ШИМ-управление скоростью |
| **TB6612FNG** | STBY | 3V3 | Драйвер всегда активен |
| **TB6612FNG** | VCC / GND | 3V3 / GND | Питание логики драйвера |
| **TB6612FNG** | VM | +12V (БП / Mini560 IN+) | Силовое питание двигателя |
| **DS18B20** | DATA | GPIO 4 | Требуется pull-up резистор 4.7 кОм на 3V3 |
| **Кнопка пуска** | Контакт 1 / 2 | GPIO 27 / GND | В коде настроен `INPUT_PULLUP` |
| **Mini560** | OUT+ / OUT- | 5V (VIN) / GND | Питание платы ESP32 |
